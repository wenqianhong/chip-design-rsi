01 · 本机直接试一次

在项目根目录打开终端。所有命令默认输出结构化 JSON；下面的 ID 用返回值替换。

./scripts/chipbench doctor
./scripts/chipbench tasks
./scripts/chipbench reset

# 编辑 reset 返回的工作区里的 ip_stride.cc / ip_stride.h
./scripts/chipbench run w-返回的工作区ID --request-id my-experiment-1
./scripts/chipbench inspect r-返回的运行ID

# completed 后，冻结这次提交，在另一组公开合成 trace 上验证
./scripts/chipbench evaluate r-返回的运行ID --request-id my-final-1

run 可用 --timeout-seconds 设置 1–3600 秒总预算（包含排队与启动）。run / evaluate 立即返回；用 inspect 查看进度。返回状态 completed 表示实验有效完成，不保证候选比基线快。HTML 路径位于 artifacts.report。

# 分页查看日志；offset 使用上次的 next_offset
./scripts/chipbench inspect r-运行ID --offset 12000 --limit 12000
./scripts/chipbench cancel r-运行ID

# Mac 重启或 Runner 意外退出后，清理已失联任务自己的 VM
./scripts/chipbench recover

03 · 在另一台 ARM Mac 上安装

需要 macOS 的 VZ 支持、Python 3.10+、网络和至少 8 GiB 可用空间（建议留 20 GiB 以上）。基础 VM 使用 2 vCPU、4 GiB 内存和 20 GiB 虚拟磁盘。

CHIPBENCH_PYTHON=/你的/python3.10/路径 bash scripts/setup-local.sh

Lima 2.3.0 安装到项目 .tools，下发的 Ubuntu 镜像有固定 SHA-256。ChampSim 固定提交 410cee62d9c429c043ea611325ce00e6c303be2a；依赖由其固定 vcpkg 子模块安装，实际 guest 软件包清单保存在 .tools/guest-packages.txt。系统 apt 仓库仍可能更新，因此不宣称跨时间逐字节可复现。

如果 VM 下载源码需要 Mac 的代理

设置 CHIPBENCH_BUILD_PROXY 为 VM 可访问的代理地址，再运行安装脚本。Lima 默认网络中宿主地址通常为 192.168.5.2；确认你的代理端口，不要直接把宿主的 127.0.0.1 填给 VM。代理只用于构建依赖，任务运行时使用独立无网络命名空间。

CHIPBENCH_BUILD_PROXY=http://192.168.5.2:你的端口 \
CHIPBENCH_PYTHON=/你的/python3.10/路径 bash scripts/setup-local.sh

04 · 这版究竟跑什么

仿真范围ChampSim 的 CPU 缓存预取器探索；不是 RTL 仿真或芯片物理设计。
输入3 条开发 + 3 条公开验证合成 trace，各 80,000 条记录。每次 warmup 10,000、测量至少 50,000 条指令。
对照no-prefetch 参照运行 1 次；ip_stride 基线和候选各重复 3 次，固定配置与 trace。
结果IPC 比值几何平均、逐 trace IPC、L2 demand MPKI、预取计数、guest 耗时和子进程峰值 RSS；RSS 不是整个 VM 峰值。
限制每工作区最多 3 次开发提交、1 次最终验证；运行串行。只允许两份预取器源文件，每份 ≤128 KiB。
失败编译错误、超时、无效统计、环境错误、取消均返回状态和日志。OOM 目前可能体现为编译或进程错误，尚无精确 OOM 分类验收。

05 · 文件在哪里

src/chipbench/          CLI、MCP、任务核心、VM worker、结果解析
environments/          Lima 配置、安装脚本、guest 执行器
tasks/prefetch-smoke/   固定任务、预取器初始文件与上游许可证
scripts/               安装、trace 生成、接入配置生成
integrations/          Agent 操作说明
.chipbench/runs/        本地运行证据和 report.html（不提交 Git）
docs/                  原始计划、开发计划、使用说明与验收记录

预取器初始源码来自 ChampSim，随附 Apache-2.0 许可证。合成 trace 由本项目脚本生成，不打包 SPEC 等受限程序轨迹。

隔离边界：VM 内不共享 Mac 目录，不携带模型凭据。Agent 本身仍在 Mac 上运行，其他终端操作不受这台 VM 保护。预取器与模拟器同进程，结果也可能被恶意代码伪造；公开排行榜需要更强评测隔离。
